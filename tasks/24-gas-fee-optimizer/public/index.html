    The example is Task 08's: 25 USDC between two public addresses seen moving USDC on Pharos Mainnet in Task 02's live proof. The fee observations are kept in this browser and shared by every transaction you time here; each run sends them, and the agent adds the newest block's. Nothing is signed or sent from this page.

    Proof & technical details

    How it decides

    1. 1get_chain_infoConfirms Pharos Mainnet, chain 1672
    2. 2get_block · get_gas_priceThe newest block's base fee and how full it is, and the node's priority fee: one observation
    3. 3get_blockWith no observations yet, five earlier blocks, 200 apart, so a first run has something to judge by
    4. 4eth_call · estimate_gasThe transaction dry-run at the same block (Task 08): would it succeed, and how much gas
    5. 5decideSend when the base fee is at or below the target, a percentile of the last 12 observations; else wait. The fee cap is the target plus the priority fee, so it never pays more
    6. 6send_raw_transactionNever from here: the hosted Chain MCP is read-only. On Atlantic the CLI sends it with --execute when the decision is to send, once

    Run it yourself
    
        
    cd agent && npm ci
node dist/src/cli.js gas --store gas.json --proof run-1.json
node dist/src/cli.js gas --store gas.json --proof run-2.json
node dist/src/cli.js verify run-1.json run-2.json
    
        
    Each run adds the newest block's fee to the store file and decides again. With atlantic-usdc and --execute, the CLI sends a 1 USDC transfer from your own testnet wallet once the decision is to send, with the capped settings; the verifier checks the signed transaction carries exactly those fees. A plan is a JSON file: any transaction Task 08 takes, a percentile or a fixed gwei target, the window, and a deadline in blocks.
