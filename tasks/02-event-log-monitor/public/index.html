      Decoding

      Only a log with exactly three topics and 32 bytes of data is decoded: topic1 is from, topic2 is to, data is the uint256 amount, shown with USDC's 6 decimals. From the zero address is a Mint, to the zero address a Burn, anything else a Transfer.

      No duplicates

      Each event is shown once, keyed by transactionHash + logIndex. The page keeps the last checked block and the keys it has shown; consecutive windows overlap, and the overlap only counts as duplicates.

      Removed logs

      A log marked removed: true is never shown as an event. If it was already shown, it is marked Removed in the feed.

      Answer
      This site's /api/events reads the last 200 blocks up to the head and shares that answer at the edge for 4 s (s-maxage=4), so every viewer is served from one upstream check. The page itself keeps the cursor and the dedup keys.
