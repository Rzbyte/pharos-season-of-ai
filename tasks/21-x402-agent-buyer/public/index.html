      How it runs
      
          
        
            
      1. 1402It asks each answer it may need once without paying, Task 25's risk check (/risk) and Task 08's dry run (/dryrun) from Task 20's x402 API: each 402 says its price, which costs nothing
        2. 
            
      2. 2planThe check first, then the dry run, each only if it fits what is left of the budget
        3. 
            
      3. 3signx402's client signs an EIP-3009 authorization only within what is left (its spend controls cap each payment there) and only at the price the 402 asked; every signed authorization counts against the budget
        4. 
            
      4. 4settleThe API's facilitator verifies it on chain through Chain MCP and settles it (transferWithAuthorization); only then does the API answer
        5. 
            
      5. 5decideWhat it bought finishes the job: do not send or check first ends it there, without the dry run; otherwise the dry run says whether the transfer would succeed, its cost, and the transaction to sign

      Run it yourself
      
        
      cd agent && npm ci
node dist/src/cli.js buy --proof buyer-mainnet.json
node dist/src/cli.js verify buyer-mainnet.json
# on Atlantic, bought, settled and finished, with your testnet keys:
PRIVATE_KEY=0x... FACILITATOR_PRIVATE_KEY=0x... node dist/src/cli.js buy --network atlantic-testnet --execute --to 0x... --proof buyer-atlantic.json
# or from an x402 API elsewhere, such as Task 20's:
PRIVATE_KEY=0x... node dist/src/cli.js buy --network atlantic-testnet --execute --to 0x... --api http://127.0.0.1:4020
      
        
      The payments cannot be replayed (a random nonce, the clock, a key made for the run), so the verifier checks their facts against the recorded Chain MCP answers: each authorization signed by the buyer for exactly its 402's price, within what was left of the budget; each settlement exactly its authorization. What can be replayed is: every answer bought is recomputed through the same code from its own recorded calls, and the job's outcome from what was bought.
