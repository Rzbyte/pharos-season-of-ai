Paste an invoice

Every figure and the payee checked, then dry-run via Pharos Chain MCP and ready to sign

Its lines as pasted: "Pay to: 0x…", amounts with their asset, a total or an amount due. Or a payment link (ethereum:…). Ctrl+Enter prepares it.

Pays the invoice. Empty: its bill-to address, else the example address.

One name = 0x… a line: addresses you have checked. An example name for an example address: edit it.

        How it prepares
        
          
          
            
        1. 1readThe invoice, by rules, not a language model: its labelled lines, the lines with an amount, its payment link. Every figure must agree with the others (the lines, the subtotal less any discount plus tax, the total less what was paid, the amount due, the link), or it is refused, saying which disagree. So is one in a currency, on another network, or with an address that fails its checksum
          2. 
            
        2. 2your payeesThe payee against the names and addresses you have checked: the same, another name, a changed address, or a new payee
          3. 
            
        3. 3get_logsThe payer's transfers of the token over the last 2,000 blocks: the same amount to the payee already, an address that starts and ends like one it pays (address poisoning), transfers of nothing to the payee
          4. 
            
        4. 4eth_call · estimate_gasThe payment as Task 17 prepares a flow: the payer's nonce, Task 08's dry run at the same block, the funds it needs with its gas
          5. 
            
        5. 5preparedThe transaction a wallet signs, the Pharos Skill Engine's cast send, and the same payment as an EIP-681 link. Anything that calls for a check holds it; the CLI sends on Atlantic, with a key, only when nothing does

        Run it yourself
        
        
        cd agent && npm ci
printf 'Example Studio = 0x…\n' > payees.txt
node dist/src/cli.js invoice invoice.txt --payees payees.txt --proof invoice.json
node dist/src/cli.js invoice "ethereum:0x…@688689?value=1e16" --payees payees.txt --network atlantic-testnet --execute
node dist/src/cli.js verify invoice.json
        
        
        The verifier reads the invoice again and replays the recorded Chain MCP answers through the same code: the same calls give exactly the recorded checks, payment and verdict, and a sent payment must be exactly its dry-run one, signed by the payer. An invoice that does not add up is never paid, and nothing is guessed: no language model reads it.
