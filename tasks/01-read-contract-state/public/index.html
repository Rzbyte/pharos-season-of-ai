    Proof & technical details

    Reads name, symbol, decimals, totalSupply and paused from Circle's USDC contract on Pharos Mainnet, all at one explicit block. MCP-only client path: this demo's server reaches Pharos through Chain MCP tools and opens no JSON-RPC connection of its own. Pharos MCP talks to the chain on its side.

    Pharos Inspector

    The inspector has its own endpoint, /api/inspect, on the same hosted Chain MCP. A contract: get_block_number, get_chain_info and eth_call ×4 at one block. A transaction: get_transaction, get_transaction_receipt and get_chain_info. scripts/check-mcp-capabilities.mjs lists the tools a server offers.

    Transcript

    Every MCP message of one CLI run against the hosted server, recorded verbatim and in order: proof/mcp-transcript.json, opens in a new tab.

    Caching
    A good read is sent with Cache-Control "public, s-maxage=15, stale-while-revalidate=45", so the edge can serve it again for up to a minute. The page marks such a response as a cached snapshot, with its age when the edge reports one. Errors are sent with no-store.
