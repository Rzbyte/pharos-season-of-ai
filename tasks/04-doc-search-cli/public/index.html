Docs Search

Ask anything documented about building on Pharos.

Try

The same search runs from a terminal, with the same result.

npm ci
npm link
pharos-docs "How do I deploy a contract with Foundry?"
pharos-docs "What is the Atlantic testnet chain ID?" --json

Exit code 0 is an answer, 1 is no answer. In this page, add --json to a question to see the raw result.

How it answers & proof
Source
Only the official Pharos Developer Docs at docs.pharos.xyz. Every answer lists the pages it comes from.
Transport
HTTPS GET to the docs' public query interface: sitemap.md for the page list, then <page>.md?ask=<question> for one or two pages. Not MCP: a public Developer Docs MCP endpoint is not documented yet.
No answer
When the matching page does not answer, or does not state the value asked for, the result is "No good answer found", never a guess.
Same as the CLI
This page calls the same search code as pharos-docs and gets the same result, as JSON with --json.
