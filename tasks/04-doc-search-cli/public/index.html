Task 04 / Doc search

Documentation Terminal

Official Pharos docs, queried from one command.

pharos-docs

Ready

Ask a question about building on Pharos. Answers come only from docs.pharos.xyz, with their source pages; when the docs do not answer, it says so. Type help for commands.

Try

How it answers

Source
Only the official Pharos Developer Docs at docs.pharos.xyz. Every answer lists the pages it comes from.
Transport
HTTPS GET to the docs' public query interface: sitemap.md for the page list, then <page>.md?ask=<question> for one or two pages. Not MCP: a public Developer Docs MCP endpoint is not documented yet.
No answer
When the matching page does not answer, or does not state the value asked for, the result is "No good answer found", never a guess.
Same as the CLI
This terminal calls the same search code as pharos-docs, and returns the same result, as JSON with --json.
