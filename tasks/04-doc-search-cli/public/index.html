04Docs Search

Ask anything documented about building on Pharos.

Answers come only from the official Pharos Developer Docs, with the pages they cite. If the docs don’t cover it, you get “No good answer found”, never a guess.

Try

How it answers

Source
Only the official Pharos Developer Docs at docs.pharos.xyz. Every answer lists the pages it cites.
Transport
The Pharos Developer Docs MCP at docs.pharos.xyz/~gitbook/mcp, over Streamable HTTP: JSON-RPC tools/list to check that askQuestion is offered, then tools/call askQuestion with the question. The pages its answer cites become the sources.
No answer
If the docs say they don’t cover it, the answer cites no docs page, or it lacks the value asked for: “No good answer found”, never a guess.
Same as the CLI
The same search code as pharos-docs, and the same result as its --json.

CLI usage

pharos-docs

The same search runs from a terminal, with the same result.

npm ci
npm link
pharos-docs "How do I deploy a contract with Foundry?"
pharos-docs "What is the Atlantic testnet chain ID?" --json

Exit code 0 is an answer, 1 is no answer. In this page, add --json to a question to see the raw result.
